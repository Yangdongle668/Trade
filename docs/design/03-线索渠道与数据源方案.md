> 日期：2026-07-03

> 本文回答两个问题：**① 线索从哪些渠道来、每个渠道的具体操作点是什么；② 用什么渠道触达客户。**

## 1. 概念区分

| 概念 | 回答的问题 | 对应需求 |
|------|-----------|----------|
| 线索发现渠道 | 目标公司名单、决策人、邮箱从哪来（数据供给） | FR-LEAD-01/02、FR-CNT-01/02 |
| 触达渠道 | 用什么载体把信息送到对方面前（送达） | FR-SEND-01~09 |

架构含义：两者都做成**插件化适配器**（NFR"扩展性"），新增一个数据源或触达渠道不改核心流水线。

## 2. 线索发现渠道详解

### 2.1 渠道总览与定位

| # | 渠道 | 角色 | 单位成本(估) | 接入难度 | 合规风险 | MVP |
|---|------|------|--------------|----------|----------|-----|
| S1 | 商业数据库 API（Apollo 类） | **底座量**：公司+联系人一站式 | $0.03–0.10/联系人 | 低（数天） | 低 | ✓ |
| S2 | Google Maps / Places API | 本地分销商/零售商/批发商 | ~$17/千条详情 | 低 | 低（官方 API） | ✓ |
| S3 | 搜索引擎 + 官网爬读（Serper/Bing API） | **差异化**：AI 研判的原料 | $1–5/千次查询 + LLM | 中 | 低–中 | ✓ |
| S4 | 美国海关提单数据（ImportGenius/Panjiva 类） | **质量王牌**：证实真实进口行为 | 年费 $3k–30k | 中 | 低（公开数据） | 二期 |
| S5 | 黄页/行业名录/展会名录 | 行业插件式增量 | 低 | 中（逐源适配） | 中（抓取条款） | 二期 |
| S6 | LinkedIn（人员数据） | 决策人补全，**不用于找公司** | $0.01–0.10/人 | 中 | **高（平台条款）** | 谨慎 |
| S7 | Email Finder + SMTP 验证（Hunter/Snov/ZeroBounce 类） | 最后一公里：邮箱与置信度 | $0.003–0.03/次 | 低 | 低 | ✓ |

### 2.2 各渠道操作点

#### S1 商业数据库 API —— MVP 主力底座

- **是什么**：Apollo.io / ZoomInfo / Cognism 等现成 B2B 数据库，覆盖北美与欧洲数千万公司，
  自带行业（SIC/NAICS）、员工数、地区、职位筛选，直接返回决策人姓名与邮箱。
- **操作点**：
  1. ICP → API 筛选条件的自动翻译：行业关键词映射行业码；「进口商/分销商/批发」映射公司关键词；
     职位定向 `purchasing | sourcing | procurement | buyer | owner | founder`；
  2. 分页拉取 → 域名归一化 → 进入研判队列（S3 补充爬读官网核实）；
  3. 数据库返回的邮箱仍过 S7 验证（第三方库有 5–15% 过期率）。
- **局限**：通用数据池，同行共用 → 必须叠加 S2/S3/S4 做增量与二次研判，否则无差异化。
- **商务点**：选型时确认「API 转售/嵌入」授权条款（多数库区分 seat license 与 API license）。

#### S2 Google Maps / Places API —— 本地实体分销商的最佳来源

- **为什么关键**：外贸目标客户常是当地有门店/仓库的进口商、批发商、零售连锁——
  这类公司 LinkedIn 不活跃，但在 Google Maps 上必然存在。
- **操作点**：
  1. 「品类词 × 城市网格」扫描：如 `lighting store / electrical wholesaler` × 目标国 Top N 城市，
     Text Search + Place Details 取公司名、官网、电话、地址、评论数、营业状态；
  2. 评论数量/评分/门店照片作为规模与活跃度信号，进入评分特征；
  3. 无官网的条目降权（无法研判、通常规模过小）；电话号码存档供 WhatsApp（三期）与人工使用。
- **合规**：使用官方 API 合规且稳定；注意其结果缓存条款（缓存期限限制）。

#### S3 搜索引擎程序化检索 + 官网爬读 —— 本产品的差异化核心

- **是什么**：AI 根据 ICP 自动生成几十种搜索式，经 SERP API（Serper/Bing）取回候选 URL，
  爬取官网关键页（首页/About/Products/News），**由 LLM 通读后输出匹配度评分与一句话理由**（FR-LEAD-03）。
- **操作点**：
  1. 查询生成：`"{品类}" distributor site:.co.uk`、`wholesale {品类} "become a dealer" {州名}`、
    `{品类} importer -alibaba -amazon` 等模板 × 关键词扩展，AI 按回收质量自动淘汰低产查询式；
  2. 爬取：robots.txt 遵从、限速、渲染兜底（JS 站用无头浏览器）；只取正文文本；
  3. 研判：便宜模型初筛（是否目标行业/是否 B2B）→ 强模型精评（匹配度 + 理由 + 事实清单，每条带出处 URL）；
  4. 研判结果缓存（域名级，90 天），同租户与跨 Campaign 复用，控制 LLM 成本（NFR"成本工程"）。
- **价值**：这一步产出的「研判档案」是个性化开发信的原料——开场引用对方官网事实（FR-GEN-01）全靠它。

#### S4 美国海关提单数据 —— 英语区首发的隐性红利

- **是什么**：美国进口提单（AMS）为公开数据，可查「谁在真实进口该品类、从哪家供应商、
  柜量与频率」——唯一能证明对方**确实购买此产品**的数据源，线索质量天花板。
- **操作点**：
  1. 按 HS Code / 品名关键词检索进口商 → 输出「已验证进口商」名单，评分直接给高分段；
  2. 竞对反查（FR-LEAD-06）：输入竞争对手公司名 → 查其美国买家 → 生成竞对客户 Campaign；
  3. 采购行为特征进研判档案：「近 12 月从中国进口 23 柜同品类」写进开发信 = 极强个性化钩子。
- **边界**：英国、欧盟、澳洲**无公开提单** → 海关数据主打美国市场；加拿大部分可得。
- **商务点**：经由数据商 API 接入（ImportGenius/Panjiva/腾道等），年费制 → 产品上作为**付费高级功能**
  （Growth 及以上套餐），成本可传导。二期接入。

#### S5 黄页 / 行业名录 / 展会名录 —— 插件式行业增量

- YellowPages.com、Yelp（美）、ThomasNet（美国工业品）、Europages、Kompass（欧）、行业协会会员名单；
- **展会参展商名录质量最高**（参展 = 有真实采购/销售意愿）：做成「按展会导入」插件
  （如 LightFair、National Hardware Show 参展商一键导入为线索池）；
- 操作点：逐源适配器 + 定期抓取/数据购买；注意各站抓取条款，优先购买官方名录数据。二期按行业逐个上。

#### S6 LinkedIn —— 只做决策人补全与半自动触达，不做黑产自动化

- **现实约束（必须向用户明示）**：LinkedIn 无面向此用途的开放 API；自动化抓取与群发违反平台条款，
  账号封禁风险高，规模化伪装还有法律风险（平台条款之外，各州反爬诉讼有先例）。
- **我们的合规操作点**：
  1. 公司已由 S1–S5 发现后，经第三方人员数据 API 补全「该公司谁管采购」（数据商合规责任前置审查）；
  2. 需要 LinkedIn 动作（加好友/站内信）时：**AI 只生成内容 → 推入业务员待办 → 业务员在自己账号一键执行**
     （FR-SEND-07 定为半自动的原因）；
  3. 绝不代持用户账号做自动化操作；绝不自建账号农场。

#### S7 邮箱发现与验证 —— 所有渠道的最后一公里

- 流水线：姓名+域名模式推测（first.last@ / f.last@ …）→ Email Finder API 交叉验证 →
  SMTP 存活探测（不发信的握手验证）→ catch-all 域名标记 → 输出置信度分级（高/中/低/catch-all）；
- **铁律**：置信度不足的邮箱不进发送队列（FR-CNT-02）——硬退信率直接决定发信域名生死（§6.3 熔断机制）。

### 2.3 MVP 渠道组合（结论）

```
公司发现   = S1 数据库（底座量） + S2 Google Maps（本地实体） + S3 搜索+官网爬读（差异化研判）
质量增量   = S4 美国海关数据（二期，付费高级功能）
决策人     = S1 自带 → 不足时 S7 Email Finder 补全 → S7 SMTP 验证兜底
LinkedIn  = 仅半自动内容生成（二期），人执行
```

**单条线索综合成本估算**（有验证邮箱的已评分线索）：$0.15–0.40
（数据 $0.03–0.15 + 搜索/爬取 $0.01–0.05 + LLM 研判 $0.05–0.15 + 验证 $0.01–0.03）。
对照套餐（Growth：1,500 条/月），数据成本占比可控，毛利成立。

## 3. 触达渠道详解

| 渠道 | 期次 | 具体操作点 | 约束 |
|------|------|-----------|------|
| **邮件（核心，≈90% 触达量）** | MVP | 用户 Gmail/Outlook OAuth 授权发送；强制独立发信域名；序列引擎控制收件人时区窗口（工作日 08:30–11:30）、单邮箱日限（预热期 ≤20，健康期 ≤50）、多账号轮换、退信熔断 | SPF/DKIM/DMARC 三绿灯才可发；压制名单全局生效 |
| 托管邮箱池 | 二期 | 平台代购发信域名+邮箱并完成预热，用户即开即用（解决冷启动） | 信誉按租户隔离 |
| LinkedIn 半自动 | 二期 | AI 生成好友申请语/跟进语 → 业务员待办 → 本人账号一键执行；执行结果回填序列 | 不自动化操作账号 |
| WhatsApp Business API | 三期 | 仅对已回复/已互动线索；模板消息经 Meta 审核；号码来自 S2 采集或客户回复落款 | 严禁冷启动群发 |
| 电话 | 不做 | 号码仅存档展示于线索档案，供业务员自行拨打 | — |

**多渠道序列示例**（二期形态）：
`D0 邮件A → D3 邮件B → D7 LinkedIn 访问+申请（人执行）→ D10 邮件C → D15 收尾` ——
任一渠道获回复，全序列停止（§6.2 不变量 1）。

## 4. 数据合规要点（英语区）

| 市场 | 规则 | 产品动作 |
|------|------|----------|
| 美国 | CAN-SPAM：允许 B2B 冷邮件，要求真实身份、物理地址、可退订 | 每封信自动附公司名+地址落款与一键退订 |
| 加拿大 | CASL（最严）：需可推定同意，B2B 相关业务豁免口径窄 | 加拿大收件人默认走保守模板 + 更强相关性校验 |
| 英国 | UK GDPR + PECR：B2B 公司邮箱冷邮件在合法利益下可行，需退订与数据来源可溯 | 数据来源记录（FR-CNT-05）+ 删除请求入口 |
| 澳新 | Spam Act：需同意或可推定同意（公开发布的商务邮箱且内容相关可推定） | 只触达公开发布的岗位邮箱，内容相关性由 ICP 保证 |

统一底线：退订/投诉 → 租户级压制名单，永不再触达（FR-RPL-05）；数据来源与采集时间全程留痕。

## 5. 架构接口（供 03-系统架构设计承接）

```
DataSourceAdapter（插件接口）
  ├─ discover(icp) → CompanyCandidate[]     // S1/S2/S3/S4/S5 各自实现
  ├─ enrich(company) → Research             // 官网爬读、海关记录等
  └─ findContacts(company) → Contact[]      // S1/S6 实现，S7 负责 verify(email)

ChannelAdapter（插件接口）
  ├─ send(step, contact) / scheduleWindow(tz)  // email 全自动
  └─ propose(step, contact) → HumanTask        // linkedin 半自动
```
