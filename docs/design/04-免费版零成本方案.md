> 日期：2026-07-03

## 1. 核心命题

免费版能否成立 = 能否把**每租户变动成本压到接近零**。变动成本只有三块：

| 成本项 | 付费方案（原 03 文档） | 免费替代 | 免费后单条线索成本 |
|--------|----------------------|----------|------------------|
| 数据 API | Apollo/海关数据/Email Finder | 免费数据源 + 自建爬取/验证 | ≈ $0（工程换钱） |
| LLM 调用 | 平台代付 $0.05–0.15/条 | **BYOK 用户自带 Key** 或 平台代付便宜模型+严配额 | $0（BYOK）/ $0.02–0.05 |
| 发信基础设施 | 托管邮箱池 + 预热服务 | 用户自有 Gmail/Outlook OAuth + 保守日限 | $0 |

结论：**可行**。代价 = 工程维护量（爬虫会坏）+ 数据覆盖率与质量打折 + 无托管预热。

## 2. 免费数据栈（替换 03 文档 §2.3 的 MVP 组合）

### 2.1 公司发现（全免费）

| 源 | 免费额度/形态 | 操作点 | 备注 |
|----|--------------|--------|------|
| Google Maps Platform | 2025 新定价：每 SKU 每月免费调用（Essentials 级约 1 万次/月） | 品类×城市网格扫描（同 03/S2） | 免费版规模下够用 |
| OpenStreetMap / Overpass API | 完全免费 | 按 `shop=lighting`、`shop=electrical` 等 tag 查 POI，取名称/官网/地址 | 覆盖不如 Google Maps，作兜底与交叉验证 |
| Google Programmable Search | 100 次/天免费（超出 $5/千次） | AI 生成搜索式（同 03/S3） | 每天可挖 30–80 家候选 |
| DuckDuckGo HTML 检索 | 免费 | 补充查询量 | 结果质量略低，作扩量 |
| **UK Companies House API** | **官方、完全免费** | 按 SIC 行业码 + 关键词查英国公司：名称、地址、状态、董事名单 | 英语区首发的宝藏源；董事名单可直接当决策人线索 |
| 美国州工商登记 / SEC EDGAR | 免费 | 公司核实与规模佐证 | 逐州适配，二阶段 |
| 展会参展商名录 | 公开网页 | 自建爬虫按展会导入（LightFair 等） | 质量最高的免费源 |
| 官网爬读 + AI 研判 | 自有算力 | 同 03/S3 操作点，研判缓存 90 天控成本 | 差异化核心保留不变 |

### 2.2 决策人与邮箱（自建替代付费 API）

1. 决策人姓名：官网 Team/About 页爬读 + Companies House 董事名单（英国）→ AI 抽取姓名/职务；
2. 邮箱推测：first.last@ / f.last@ / first@ 等模式生成候选；
3. 验证：**自托管开源 SMTP 验证器**（如 check-if-email-exists / Reacher）——
   独立干净 IP 的小型 VPS 部署，握手验证不发信，零 API 费；catch-all 域名标记降级；
4. 兜底：官网公开的 sales@/info@ 仅在无具名联系人时使用，并在信中请求转交（"could you point me to whoever handles sourcing?"）。

### 2.3 明确砍掉（转为未来付费版卖点）

Apollo 类数据库 · 美国海关提单数据 · 付费 Email Finder · 托管邮箱池与预热服务 · SERP 付费 API 扩量。

## 3. LLM 成本：BYOK 为主，配额为辅

- **BYOK（Bring Your Own Key）**：用户在设置中填自己的模型 API Key，研判与写信调用计入用户账单。
  平台零 LLM 成本——海外开源增长工具的成熟模式；
- 平台代付模式（可选开关）：仅用便宜模型做初筛+写信，强模型只精评评分 ≥80 的线索；
  免费配额示例：**100 条研判线索/月 + 300 封生成/月**；
- 研判结果按域名缓存 90 天、跨租户共享公司公开事实（注意：仅公开网页事实可共享，联系人数据不共享）。

## 4. 发信：用户自有邮箱 + 保守护栏

- Gmail / Outlook OAuth 授权，经用户自己的账号发送（原生免费）；
- **免费版日限锁定 ≤20 封/邮箱**——量小即最好的信誉保护，把"没有托管预热"转化为合理的产品分层；
- SPF/DKIM/DMARC 检测器保留（纯 DNS 查询，零成本），三绿灯才解锁发送；
- 退信熔断、压制名单、时区窗口等护栏全部保留（工程成本，非变动成本）。

## 5. 免费版产品定义（v0）

| 维度 | 免费版 v0 |
|------|-----------|
| 席位 | 1（SOHO 画像优先） |
| 线索 | 100 条已研判线索/月 |
| 发信邮箱 | 1 个（自有 Gmail/Outlook） |
| 日发送 | ≤20 封 |
| 自动化级别 | 全部（逐封/抽检/全自动） |
| LLM | BYOK 不限（在配额内）/ 平台代付走小配额 |
| 数据源 | 免费栈（§2） |
| 未来付费钩子 | 海关数据、托管邮箱池、更多席位/配额、团队看板、CRM 推送 |

**免费版的战略回报**：真实用户的回复率/分类反馈数据 → 训练评分与话术优化模型；
用户拿到第一条热线索的时刻 = 天然付费转化点。

## 6. 诚实的代价清单（需求方已知悉）

1. 爬虫与免费源需要持续维护（页面改版、限流），工程量高于付费 API；
2. 线索覆盖率与产出速度低于付费栈（尤其美国市场缺少现成决策人库，更依赖官网挖人）；
3. 无托管预热 → 新用户前 2–3 周产出慢，Onboarding 预期管理文案必须到位；
4. SMTP 自建验证在部分严格邮服（如 Yahoo）准确率有限 → 置信度分级要更保守；
5. BYOK 提高了小白用户门槛 → 提供"申请 Key 图文指引"，或平台代付小配额作缓冲。
